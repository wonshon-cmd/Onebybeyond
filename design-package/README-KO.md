# ONE TO BEYOND — 웹사이트 인계 패키지

이 ZIP 전체를 다른 AI나 개발자에게 전달하세요. 먼저 `AI-HANDOFF-KO.txt`를 읽게 하세요.

## 무엇이 들어 있나요?

- `index.html` + `style.css` + `app.js`: 정적 호스팅에 올릴 수 있는 분리된 웹사이트 소스. 사용자가 선택한 오프화이트 Editorial Letter를 기준으로 하며 후원 메뉴·섹션은 제거했습니다.
- `assets/photos/`: 원본 HTML에 포함되었던 실제 사진. 외부 이미지 사이트에 의존하지 않습니다.
- `assets/one-to-beyond-logo.svg`: 선택한 얇은 사선 로고.
- `content.json`: 글과 사진 경로를 살펴보기 쉬운 내용 파일. 현재 실행본은 index.html 안의 `embedded-data`를 읽습니다. 이 JSON을 수정하면 자동 반영되는 구조는 아직 아닙니다.
- `reference/approved-design.html`: 사용자가 마지막으로 승인한 디자인 원본. 글꼴·필기체·목차·여백의 최우선 기준입니다.
- `offline-preview.html`: 위 디자인을 한 파일로 바로 열어 보는 버전. 당시 디자인 원본이므로 이전 데모 메뉴가 남아 있을 수 있습니다.
- `admin.html`: 그동안 개발한 관리자/편집 기능의 통합 데모. 관리자 화면을 열어야 편집할 수 있으며, 이 파일의 공개 화면 디자인을 최종 기준으로 삼지 마세요.
- `DESIGN-SYSTEM.md`: 고정할 디자인과 UX 기준.
- `AI-HANDOFF-KO.txt`: 다음 AI에게 그대로 전달할 작업 지시.

## 열기

컴퓨터에서 `index.html`을 브라우저로 열면 같은 폴더의 CSS/JS/사진을 읽습니다. 전체 폴더 구조를 유지하세요. 개발 서버를 쓰려면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 localhost:8000을 여세요.

한 파일 오프라인 확인은 `offline-preview.html`로 가능합니다. 아이폰의 파일 미리보기는 JavaScript·글꼴 동작을 제한할 수 있습니다.

## 현재 범위

정적 프로토타입입니다. 로컬 저장·로그인 체험·반응은 방문자 공용 서버에 저장되지 않습니다. `admin.html`의 이메일/비밀번호는 로컬용이며 실제 계정 인증이나 접근 제어가 아닙니다. 이메일·카카오 자동발송과 기기 간 자동 동기화는 연결되어 있지 않습니다. 결제 기능은 필요하지 않으며 후원 섹션을 다시 넣지 마세요.

## 배포 전 필수 통합

현재 `index.html`과 `admin.html`은 서로 다른 데모의 저장 구조입니다. 관리자에서 반영해도 index.html의 내용이 자동으로 바뀌지 않습니다. 다음 AI가 승인 디자인을 유지하면서 관리자 기능을 하나의 콘텐츠 모델로 통합하고 인증·DB·파일 저장을 연결해야 실제 운영할 수 있습니다. 이 상태를 운영 서비스로 오해하지 마세요.
