# 확정된 시각 기준

최우선: reference/approved-design.html. 사용자가 “로고 빼고는 글자체랑 모든게 이게 좋아”라고 선택한 파일입니다.

- 배경 #FAF9F6, 종이 #FFFFFF, 본문 #343733, 보조 #6F746C, 선 #E2E0D9, 기존 편집 포인트 #8B7D6B.
- 로고만 오렌지 #FF7900 / 그린 #009E60 사선 두 개 + 검정 ONE TO BEYOND. 얇고 간결한 가로형 로고.
- 본문 글꼴은 승인 파일의 시스템 고딕 조합과 굵기·행간을 기준으로 유지하세요. Noto Light를 다시 전체에 강제 적용하지 마세요. 사용자는 시안의 글꼴보다 첨부 파일의 실제 한글을 최종 선호했습니다.
- 기존 필기체/이탤릭 Bonjour, Côte d’Ivoire, FROM THE FIELD 목차, 01 만남의 복 등 세리프 숫자와 한글 제목의 조합을 유지하세요.
- Au fil des jours 문구는 넣지 마세요.
- 표지: 제목·소제목·사진. 첫 표지에는 공유/이모지 선택을 넣지 않습니다. 소식지 보기나 사진을 누르면 본문으로.
- 표지 다음 본문은 한 페이지 스크롤입니다.
- 이야기 끝에는 하트만. 기도제목에는 ✧ 아멘 0 → ✓ 함께 기도했어요 1, 다시 누르면 해제. 추가 이모지·플러스 선택은 금지.
- 아멘 선택 시 옅은 웜그레이 배경과 차분한 테두리의 둥근 버튼.
- 기존 무명 영상 https://www.youtube.com/watch?v=Ie07qxjnmGI 는 미리보기+외부 열기. 인터넷 없이는 영상 재생 불가.
- 후원·결제 섹션은 제거. 초록 전체 배경이나 큰 색 패널을 다시 넣지 마세요.
- 사진 좌표는 GPS/입력값이 확인된 경우만. 디자인 예시 좌표를 실제 촬영 위치로 표시하지 마세요.
